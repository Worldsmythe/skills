# Worldsmythe's Agent Skills

This is a collection of skills that I use.

## Skills

- `ai-dungeon` - This is a skill for AI Dungeon: scenario design, scripting, and gameplay.

## Installation

Via `skills`:

`npx skills add worldsmythe/skills --skill ai-dungeon`

Via `.skill`:

Download from the [latest release](https://github.com/Worldsmythe/skills/releases/latest), or grab a skill directly:

- [`ai-dungeon.skill`](https://github.com/Worldsmythe/skills/releases/latest/download/ai-dungeon.skill)
