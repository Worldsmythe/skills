# Worldsmythe's Agent Skills

Personal agent skills.

## Skills

- `ai-dungeon` — AI Dungeon platform, GraphQL API, and the bundled `aid` CLI (data inspection and account management).
- `ai-dungeon-scenario-design` — designing AI Dungeon scenarios: plot components, story cards, branch trees, placeholders, tags, and the community script catalog.
- `ai-dungeon-gameplay` — playing AI Dungeon adventures: context management, course-correction, and troubleshooting.
- `ai-dungeon-scripting` — writing AI Dungeon JavaScript scenario scripts.

## Installation

Via `skills`:

```
npx skills add worldsmythe/skills --skill ai-dungeon
npx skills add worldsmythe/skills --skill ai-dungeon-scenario-design
npx skills add worldsmythe/skills --skill ai-dungeon-gameplay
npx skills add worldsmythe/skills --skill ai-dungeon-scripting
```

Via `.skill`:

Download from the [latest release](https://github.com/Worldsmythe/skills/releases/latest), or grab a skill directly:

- [`ai-dungeon.skill`](https://github.com/Worldsmythe/skills/releases/latest/download/ai-dungeon.skill)
